# Projeto: Chamado de Suporte

O projeto consiste no desenvolvimento de uma aplicação web para gerenciamento de chamados de suporte, utilizando tecnologias como **HTML, CSS, JavaScript, TypeScript e Node.js**.

## Tutorial de utilização

1. Crie uma pasta para armazenar o projeto em um diretório de fácil acesso. Recomenda-se evitar espaços e caracteres especiais no caminho.

   **Exemplo:** `C:\projetos\Chamado-de-Suporte`

2. Abra o terminal dentro da pasta do projeto e execute o comando `npm run dev` para iniciar a aplicação.

3. Após a inicialização, acesse o endereço disponibilizado no terminal, geralmente `http://localhost:5173`.

> [!IMPORTANT]
> **Atenção:** Não abra o arquivo `index.html` diretamente pelo navegador, seja por dois cliques ou pelo caminho do arquivo.
>
> Para que a aplicação carregue corretamente e todas as funcionalidades estejam disponíveis, é necessário iniciá-la pelo comando `npm run dev` no terminal, sempre dentro da pasta do projeto.
